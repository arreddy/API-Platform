Java stack details
Control Plane (services/control-plane/)

Spring Boot 3.2, Spring Security (stateless JWT), Spring Data JPA
hypersistence-utils for JSONB @Type mapping on PostgreSQL
swagger-parser for OAS 3.0/3.1 validation
auth0/java-jwt for JWT generation/verification
BCryptPasswordEncoder for API key hashing
Flyway auto-runs migrations on startup
Dev mode: auto-injects default admin principal when no Authorization header
Gateway (services/gateway/)

Spring Cloud Gateway (Project Reactor / Netty) — reactive, non-blocking
ProxyRegistry polls control plane every 30s via WebClient
ApiKeyAuthFilter validates keys with 60s in-memory cache
RateLimitFilter uses Redis sliding window, falls back to in-memory ConcurrentHashMap
RequestLogFilter (GlobalFilter) batches analytics to control plane every 5s or 100 entries
Mock Server (services/mock-server/)

Spring Boot with MockGeneratorService using datafaker (Java Faker)
@Cacheable("oas-documents") caches OAS docs from control plane for 2 min
Schema-aware generation: objects, arrays, strings (format-aware), numbers, booleans
